## Notes

- Freesound "direct file" links are Freesound's own 128 kbps MP3 previews of the originals (the WAV/FLAC originals need a
  Freesound login). The licence attaches to the recording, not the encoding; re-download the originals with an account if
  higher quality is wanted. The lonemonk and Sandermotions files were taken as originals from the Wikimedia Commons mirrors.
- Processing: static ffmpeg 7.0.2 (imageio-ffmpeg build). One-shots: trim, silence removal at -45/-50 dB, 20 ms fade-in,
  300 ms fade-out, peak normalised to -1 dBFS, libmp3lame 128 kbps CBR, 44.1 kHz. Loops: no fades, crossfaded seam, same
  normalisation and encoding. MP3 adds ~30 ms encoder padding; players that honour the LAME gapless header trim it. If a
  gap is audible when looping `murmur.mp3` / `room-tone-club.mp3`, re-encode those two as OGG from the same sources.
- `snaps.mp3` is a sound-design construction from single-person snaps, not a recording of an audience. It is labelled as
  such here so it can be dropped if a real recording is preferred.
- Selection was made from the authors' descriptions, tags and RMS-envelope analysis, not by ear; audition before shipping.
